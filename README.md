# NUKE Mods

تطبيق عربي مجاني لتنزيل مودات الألعاب وتثبيتها بضغطة زر.

## التحميل

نزّل آخر نسخة من **[Releases](https://github.com/nukegcc/nuke-mods/releases/latest)** (الملف `NUKE Mods Setup … .exe`).

بعد التثبيت، التطبيق يحدّث نفسه بروحه.

---

A free Arabic-first app to download and install game mods in one click.
Get the latest version from **[Releases](https://github.com/nukegcc/nuke-mods/releases/latest)**. The app updates itself after that.
